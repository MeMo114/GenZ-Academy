# GenZ Academy

GenZ Academy is a learning management platform developed for ElSewedy Academy.

## Project Structure

```text
GenZ
├── front    # Frontend Application
├── back     # ASP.NET Core Backend
└── docs     # Project Documentation
```

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- ASP.NET Core
- Entity Framework Core
- SQL Server

## Features

- Student Management
- Instructor Management
- Cohort Management
- Enrollment Management
- Attendance Tracking
- Assignments & Assessments
- Dashboard & Reporting

## Getting Started

### Frontend

```bash
cd front
npm install
npm run dev
```

### Backend

```bash
cd back
dotnet restore
dotnet run
```

## Deployment

### Frontend
- Vercel

### Backend
- MonsterASP.NET
